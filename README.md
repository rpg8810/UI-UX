## Final Conclusion Summary
The goal of this study was to conduct an individual mixed-methods usability evaluation comparing the original Ola ride-hailing interface against a modified high-fidelity Figma prototype. 

The redesign focused on reducing cognitive load, guaranteeing price transparency, and streamlining active-ride controls. Qualitative feedback from 5 participants confirmed that the modified prototype successfully resolved core frustrations, specifically addressing unexpected price hikes, cluttered navigation, and poor visual ergonomics. By moving to a fixed-fare model and prioritizing recent destinations on the home screen, the redesign significantly improved task completion speed and overall user satisfaction.
